# CR-Assistant
در این پروژه من قصد داشتم که یک دستیار صوتی آفلاین درست کنم.

کار این دستیار صوتی شامل زنگ زدن از روی اسم در لیست مخاطبین,باز کردن برنامه ها,گفتن تاریخ و زمان,جستوجو در وب هستش.

این دستیار یک هوش مصنوعی هم دارد که اگه میخوایید میتونید از هر مدلی استفاده کنید ولی به شخصه از مدل vosk-module-small-fa استفاده کردم که کار هوش مصنوعی تبدیل صوت به متن هستش.

این دستیار صوتی به صورت عادی از صدا استفاده نمیکند و توی یک متن در قسمت پایین صفحه موبایل جواب را میدهد ولی اگه میخواهیید به دستیار صدا بدهید میتوانید از موتور صدای TTS استفاده کنید.
